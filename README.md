# Video Küçültücü / Bant Kırpıcı

MP4 ve video dosyalarındaki üst/alt siyah ve beyaz bantları otomatik veya manuel olarak tespit edip kırpan Tkinter tabanlı masaüstü aracı.

## Özellikler
- **Otomatik Algılama**: Siyah/beyaz bantları ve hareketsiz kenar bölgelerini otomatik tespit eder.
- **Manuel Kırpma**: Çizgileri sürükleyerek kırpma sınırlarını elle ayarlama.
- **FFmpeg & OpenCV Desteği**: Hızlı ve kayıpsız video işleme.
- **Tamamen Çevrimdışı**: Herhangi bir internet bağlantısı veya API anahtarı gerektirmez.

## Kurulum

```bash
pip install -r requirements.txt
```

## Kullanım

```bash
python videokucultucu.py
```
